Anatomy of a RAW

A camera does not record a picture. It records one brightness number per photosite, under a grid of coloured filters. This page runs irradiance, a pure-Rust RAW library compiled to WebAssembly, on a real file and shows every step. Hover the image to follow a single pixel.

      irradiance is MIT OR Apache-2.0, pure Rust, with no runtime dependencies and no unsafe. It takes bytes and returns pixels: no file I/O, no network. Here it runs as a few hundred KB of WebAssembly.
      
    
      Sample photo: Nikon D300S, from raw.pixls.us (CC0). Full frames for stages 1–4 are shown linear, as the data really is; the loupe brightens them so detail is visible.
